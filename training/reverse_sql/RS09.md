# RS09 — Reverse SQL

No business question is given. Study the SQL below and answer, before
looking at the solution:

1. What does one output row represent (the grain)?
2. What business metric is being computed?
3. What analytical pattern does this use?
4. What is the most likely business question this query was written to
   answer?

```sql
SELECT
    p.category_id,
    COUNT(DISTINCT r.order_id) AS orders_with_return,
    COUNT(DISTINCT oi.order_id) AS total_orders,
    ROUND(
        COUNT(DISTINCT r.order_id) * 100.0 / COUNT(DISTINCT oi.order_id),
        2
    ) AS return_rate_pct
FROM order_items oi
JOIN products p ON p.product_id = oi.product_id
JOIN orders o ON o.order_id = oi.order_id
LEFT JOIN returns r ON r.order_id = oi.order_id AND r.product_id = oi.product_id
WHERE o.order_status = 'completed'
GROUP BY p.category_id;
```
