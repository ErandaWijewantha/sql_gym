# RS03 — Reverse SQL

No business question is given. Study the SQL below and answer, before
looking at the solution:

1. What does one output row represent (the grain)?
2. What business metric is being computed?
3. What analytical pattern does this use?
4. What is the most likely business question this query was written to
   answer?

```sql
SELECT
    c.category_name,
    SUM(oi.quantity * oi.unit_price) AS total_revenue
FROM orders o
JOIN order_items oi ON oi.order_id = o.order_id
JOIN products p      ON p.product_id = oi.product_id
JOIN categories c     ON c.category_id = p.category_id
WHERE o.order_status = 'completed'
GROUP BY c.category_name
HAVING SUM(oi.quantity * oi.unit_price) > 50000000
ORDER BY total_revenue DESC;
```
