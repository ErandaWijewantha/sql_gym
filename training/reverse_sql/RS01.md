# RS01 — Reverse SQL

No business question is given. Study the SQL below and answer, before
looking at the solution:

1. What does one output row represent (the grain)?
2. What business metric is being computed?
3. What analytical pattern does this use?
4. What is the most likely business question this query was written to
   answer?

```sql
SELECT
    customer_id,
    order_id,
    order_date
FROM (
    SELECT
        customer_id,
        order_id,
        order_date,
        ROW_NUMBER() OVER (PARTITION BY customer_id ORDER BY order_date DESC) AS rn
    FROM orders
) ranked
WHERE rn = 1;
```
