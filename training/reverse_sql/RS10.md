# RS10 — Reverse SQL

No business question is given. Study the SQL below and answer, before
looking at the solution:

1. What does one output row represent (the grain)?
2. What business metric is being computed?
3. What analytical pattern does this use?
4. What is the most likely business question this query was written to
   answer?

```sql
SELECT customer_id, total_spend
FROM (
    SELECT
        c.customer_id,
        SUM(oi.quantity * oi.unit_price - oi.discount_amount) AS total_spend
    FROM customers c
    JOIN orders o ON o.customer_id = c.customer_id AND o.order_status = 'completed'
    JOIN order_items oi ON oi.order_id = o.order_id
    GROUP BY c.customer_id
) customer_totals
WHERE total_spend > (
    SELECT AVG(total_spend) FROM (
        SELECT SUM(oi2.quantity * oi2.unit_price - oi2.discount_amount) AS total_spend
        FROM customers c2
        JOIN orders o2 ON o2.customer_id = c2.customer_id AND o2.order_status = 'completed'
        JOIN order_items oi2 ON oi2.order_id = o2.order_id
        GROUP BY c2.customer_id
    ) all_totals
);
```
