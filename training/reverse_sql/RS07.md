# RS07 — Reverse SQL

No business question is given. Study the SQL below and answer, before
looking at the solution:

1. What does one output row represent (the grain)?
2. What business metric is being computed?
3. What analytical pattern does this use?
4. What is the most likely business question this query was written to
   answer?

```sql
WITH monthly AS (
    SELECT
        store_id,
        DATE_FORMAT(order_date, '%Y-%m-01') AS month_start,
        COUNT(*) AS order_count
    FROM orders
    WHERE order_status = 'completed'
    GROUP BY store_id, DATE_FORMAT(order_date, '%Y-%m-01')
)
SELECT
    store_id,
    month_start,
    order_count,
    LAG(order_count) OVER (PARTITION BY store_id ORDER BY month_start) AS prev_order_count,
    ROUND(
        (order_count - LAG(order_count) OVER (PARTITION BY store_id ORDER BY month_start))
        / NULLIF(LAG(order_count) OVER (PARTITION BY store_id ORDER BY month_start), 0) * 100,
        1
    ) AS pct_change
FROM monthly
ORDER BY store_id, month_start;
```
