# RS02 — Reverse SQL

No business question is given. Study the SQL below and answer, before
looking at the solution:

1. What does one output row represent (the grain)?
2. What business metric is being computed?
3. What analytical pattern does this use?
4. What is the most likely business question this query was written to
   answer?

```sql
SELECT o1.customer_id, o1.order_date AS earlier_order, o2.order_date AS later_order,
       DATEDIFF(o2.order_date, o1.order_date) AS gap_days
FROM orders o1
JOIN orders o2
    ON o1.customer_id = o2.customer_id
   AND o2.order_date > o1.order_date
WHERE NOT EXISTS (
    SELECT 1 FROM orders o3
    WHERE o3.customer_id = o1.customer_id
      AND o3.order_date > o1.order_date
      AND o3.order_date < o2.order_date
)
AND DATEDIFF(o2.order_date, o1.order_date) >= 90;
```
