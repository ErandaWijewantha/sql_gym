# RS08 — Reverse SQL

No business question is given. Study the SQL below and answer, before
looking at the solution:

1. What does one output row represent (the grain)?
2. What business metric is being computed?
3. What analytical pattern does this use?
4. What is the most likely business question this query was written to
   answer?

```sql
SELECT
    oi1.product_id AS product_a,
    oi2.product_id AS product_b,
    COUNT(DISTINCT oi1.order_id) AS co_occurrence_count
FROM order_items oi1
JOIN order_items oi2
    ON oi1.order_id = oi2.order_id
   AND oi1.product_id < oi2.product_id
JOIN orders o ON o.order_id = oi1.order_id
WHERE o.order_status = 'completed'
GROUP BY oi1.product_id, oi2.product_id
ORDER BY co_occurrence_count DESC
LIMIT 10;
```
